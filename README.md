# Dicee --- The Dice Game

A simple two-player dice game built with HTML, CSS, and JavaScript.

## Live Demo

Coming soon.

## About the Project

Dicee is a small JavaScript project from my web development learning
journey. Each time the page is refreshed, two dice roll randomly. The
page announces whether Player 1 wins, Player 2 wins, or the result is a
draw.

## Features

-   Random dice rolls for two players
-   Six possible outcomes for each die
-   Automatic winner or draw message
-   Simple page layout

## Built With

-   HTML5
-   CSS3
-   JavaScript

## How to Run Locally

1.  Download or clone this repository.
2.  Keep `index.html`, `index.js`, and the `images` folder in the same
    structure shown above.
3.  Open `index.html` in your web browser.
